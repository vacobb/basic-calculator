# Calculator GUI (Java AWT)
## Overview

This project is a desktop calculator application built using Java AWT. The purpose of the project is to learn GUI development concepts including layouts, event handling, user interaction, and object-oriented design.

The application uses multiple layout managers and event listeners to create an interactive user interface similar to a basic calculator.

### Technologies Used
- Java
- Java AWT
- IntelliJ IDEA
  
### Features

Current functionality:

- Calculator window with display area
- Button-based user interface
- Grid-based button layout using GridBagLayout
- Display area using TextField
- Shared ActionListener for button interactions
- Window close functionality
- Concepts Practiced

### This project demonstrates:

- Event-driven programming
- GUI component creation
- Layout management
  - BorderLayout
  - FlowLayout
  - GridBagLayout
- Nested panels
- ActionListeners
- Object references
- Type casting
- Object-oriented programming principles

### Project Structure
Calculator
├── Display Panel
│   └── TextField
│
└── Button Panel
    ├── Number Buttons
    ├── Operator Buttons
    └── Action Buttons

### Running the Application
1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Compile and run Calculator.java.
4. Interact with the calculator using the GUI buttons.

### Learning Objectives

Through this project I learned how to:

- Build desktop interfaces using Java AWT
- Organize GUIs using nested layouts
- Handle button events with ActionListeners
- Use shared listeners to reduce duplicate code
- Manage component references for dynamic updates
- Separate interface design from application logic
